# 🎨 Icons Directory

This directory contains the icon files required for the Delta Baba Sniper 18.0 Chrome extension.

## 📁 Required Icon Files

The extension requires the following icon files in different sizes:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon32.png` - 32x32 pixels (Windows taskbar)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## 🎯 Icon Specifications

- **Format**: PNG (recommended) or ICO
- **Background**: Transparent or solid color
- **Design**: Should represent the extension's purpose (trading/scanner)
- **Colors**: Should work well on both light and dark themes

## 🔧 Creating Icons

### Option 1: Use Design Software
- **Adobe Illustrator/Photoshop**: Create vector or raster icons
- **Figma**: Free online design tool
- **Canva**: Simple icon creation

### Option 2: Icon Generators
- **Favicon.io**: Generate multiple sizes from one image
- **RealFaviconGenerator**: Professional favicon generation
- **IconKitchen**: Google's icon generator

### Option 3: Download Icons
- **Flaticon**: Free icon downloads
- **Icons8**: Professional icon library
- **Material Icons**: Google's icon set

## 📐 Icon Design Guidelines

1. **Simplicity**: Keep designs simple and recognizable at small sizes
2. **Consistency**: Use consistent style across all sizes
3. **Readability**: Ensure icons are clear even at 16x16 pixels
4. **Branding**: Include rocket 🚀 or trading-related symbols
5. **Colors**: Use colors that match the extension's theme

## 🚀 Recommended Icon Design

For Delta Baba Sniper 18.0, consider using:
- **Primary Symbol**: Rocket 🚀 (represents speed and precision)
- **Secondary Elements**: Chart lines, candlesticks, or trading symbols
- **Color Scheme**: Blue (#2196f3) and Orange (#ff9800) to match the extension
- **Style**: Modern, professional, and tech-focused

## 📋 Icon Checklist

Before using icons, ensure they:
- [ ] Are available in all required sizes
- [ ] Have transparent backgrounds (if applicable)
- [ ] Are visually consistent across sizes
- [ ] Represent the extension's purpose clearly
- [ ] Work well on both light and dark themes
- [ ] Meet Chrome Web Store requirements

## 🔄 Updating Icons

To update the extension icons:

1. **Replace Icon Files**: Put new icons in this directory
2. **Update manifest.json**: Ensure icon paths are correct
3. **Test Extension**: Verify icons display properly
4. **Reload Extension**: Use "Reload" button in Chrome extensions page
