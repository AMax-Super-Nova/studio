# 🚀 Quick Installation Guide

## Install Delta Baba Sniper 18.0 in 3 Simple Steps

### Step 1: Open Chrome Extensions
1. Open **Google Chrome**
2. Type `chrome://extensions/` in the address bar
3. Press **Enter**

### Step 2: Enable Developer Mode
1. Toggle **"Developer mode"** in the top-right corner
2. You'll see new buttons appear

### Step 3: Load the Extension
1. Click **"Load unpacked"** button
2. Navigate to and select the **"Delta Baba Sniper 18.0"** folder
3. Click **"Select Folder"**

## ✅ Installation Complete!

You should now see **Delta Baba Sniper 18.0** in your extensions list with a green checkmark.

## 🎯 First Use

1. **Go to** [Delta Exchange India](https://delta.exchange)
2. **Select** any trading pair (e.g., BTC/USDT)
3. **Click** the Delta Baba Sniper icon in your Chrome toolbar
4. **Click** "Start Scanning" to begin analysis

## 🔧 Troubleshooting

- **Extension not showing?** Refresh the extensions page
- **Permission errors?** Click "Details" and allow permissions
- **Not working?** Make sure you're on delta.exchange website
