# 🚀 Quick Installation Guide

## Install Delta Baba Sniper 18.0

### Step 1: Download & Extract
- Download the `Delta Baba Sniper 18.0` folder
- Extract it to a permanent location on your computer

### Step 2: Open Chrome Extensions
- Open Chrome browser
- Go to `chrome://extensions/`
- Or: Chrome Menu → More Tools → Extensions

### Step 3: Enable Developer Mode
- Toggle "Developer mode" switch (top-right corner)

### Step 4: Load Extension
- Click "Load unpacked" button
- Select the `Delta Baba Sniper 18.0` folder
- Extension should appear in your extensions list

### Step 5: Pin Extension
- Click the puzzle piece icon in Chrome toolbar
- Find "Delta Baba Sniper 18.0" and click the pin icon

### Step 6: Start Using
- Navigate to [Delta Exchange](https://delta.exchange)
- Click the extension icon to open the trading interface

## ✅ Verification
- Extension icon should appear in Chrome toolbar
- Icon should be active when on Delta Exchange
- Popup should open when clicking the icon

## 🆘 Troubleshooting
- **Extension not loading**: Check Developer Mode is enabled
- **No data**: Ensure you're on Delta Exchange website
- **Icons missing**: Check if all files are in the folder
