## 🚀 Installation Steps

1. **Navigate to Chrome Extensions**
   - Go to `chrome://extensions/`
   - Enable "Developer mode"

2. **Load Extension**
   - Click "Load unpacked"
   - Select the `Delta Baba Sniper 18.0` folder

3. **Start Using**
   - Navigate to Delta Exchange
   - Click the extension icon
